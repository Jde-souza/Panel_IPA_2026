# Instrucciones para Agentes de IA (AGENTS.md)

Toda la documentación de contexto, arquitectura, base de datos, componentes y reglas de negocio para agentes de IA se encuentra organizada en la carpeta [`ai-context/`](./ai-context/):

- **[`ai-context/00-INDEX-AGENTS.md`](./ai-context/00-INDEX-AGENTS.md)**: Índice general, comandos rápidos y reglas de oro del proyecto.
- **[`ai-context/01-ARCHITECTURE-AND-STACK.md`](./ai-context/01-ARCHITECTURE-AND-STACK.md)**: Stack tecnológico, estructura de carpetas y flujo híbrido de datos.
- **[`ai-context/02-BACKEND-AND-DATABASE.md`](./ai-context/02-BACKEND-AND-DATABASE.md)**: Esquema SQLite (`database.sqlite`), endpoints Express (`/api/*`) y mapeo de datos.
- **[`ai-context/03-FRONTEND-COMPONENTS-AND-SERVICES.md`](./ai-context/03-FRONTEND-COMPONENTS-AND-SERVICES.md)**: Componentes Angular Standalone, servicios, temas ANEP y accesibilidad.
- **[`ai-context/04-SCRAPERS-AND-AUTOMATION.md`](./ai-context/04-SCRAPERS-AND-AUTOMATION.md)**: Scripts `extract_*.js`, fuentes de Google Sheets/ANEP y sincronización con SQLite.

Lee siempre [`ai-context/00-INDEX-AGENTS.md`](./ai-context/00-INDEX-AGENTS.md) al iniciar una tarea en este repositorio.
